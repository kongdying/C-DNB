We developed C-DNB, a cell–cell similarity-optimized dynamic network biomarker method designed for time-series single-cell RNA sequencing data. C-DNB identifies critical state transitions during glioblastoma (GBM) progression while accounting for cellular heterogeneity.​Two independent tipping points were identified during GBM progression.​T1 marks the transition from quiescent neural stem cells to oncogenic proliferation.​T3 marks the activation of stress-driven signaling associated with tumor invasion.​T1- and T3-associated DNB scores showed prognostic value across five clinical cohorts.​ Using our self-built Rev-DNB screening strategy, we pinpointed 10 FDA-approved repurposed drugs, such as Rucaparib and Sirolimus, which effectively reverse tipping-point malignant signatures and offer clinically actionable interventions for GBM. The repository provides code for C-DNB analysis, trajectory analysis, clinical validation, regulatory network analysis, virtual perturbation and drug-repurposing analysis.

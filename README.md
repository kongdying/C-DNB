# Cell Similarity-Optimized Dynamic Network Biomarker for Glioblastoma
Glioblastoma multiforme (GBM) exhibits devastating clinical outcomes, largely due to poorly defined oncogenic transition mechanisms and the absence of actionable early-warning biomarkers that capture its stepwise malignant progression. We developed C-DNB, a cell–cell similarity-optimized dynamic network biomarker method designed for time-series single-cell RNA sequencing data. C-DNB identifies critical state transitions during glioblastoma (GBM) progression while accounting for cellular heterogeneity.​Two independent tipping points were identified during GBM progression.​T1 marks the transition from quiescent neural stem cells to oncogenic proliferation.​T3 marks the activation of stress-driven signaling associated with tumor invasion.​T1- and T3-associated DNB scores showed prognostic value across five clinical cohorts.​ Using our self-built Rev-DNB screening strategy, we pinpointed 10 FDA-approved repurposed drugs, such as Rucaparib and Sirolimus, which effectively reverse tipping-point malignant signatures and offer clinically actionable interventions for GBM. The repository provides code for C-DNB analysis, trajectory analysis, clinical validation, regulatory network analysis, virtual perturbation and drug-repurposing analysis.

**Data  availability**

The scRNA-seq data were obtained from https://doi.org/10.6084/m9.figshare.11610870. Five independent glioma cohorts with transcriptomic and clinicopathological data were collected from The Cancer Genome Atlas (TCGA,n = 702), the Chinese Glioma Genome Atlas (CGGA,n = 693 and 325), CGGA microarray (n = 301), and Repository of Molecular Brain Neoplasia Data (Rembrandt,n = 475).LINCS L1000 includes drug-perturbed gene expressionprofiles of 720216 small molecule instances available from NIH LINCS(https://incsproject.org/LINCS/tools/workflows/find-the-best-place-to-obtain-the-lincs-11000-data).
